Frequently Asked Questions

Everything you need to know about Pulse-Width Modulation and ZeroDimmer.

What is PWM screen flicker and why does it cause headaches? ▼
Pulse-Width Modulation (PWM) is a technique display manufacturers use to simulate lower brightness by cycling the screen backlight on and off at rapid intervals (200Hz - 2000Hz). Even when imperceptible to conscious vision, this constant strobing forces your iris and ciliary eye muscles to rapidly contract and dilate, causing severe eye fatigue, tension headaches, and ocular migraines.
How does ZeroDimmer eliminate PWM backlight strobing? ▼
When hardware screen brightness is kept at 100%, modern display backlights run on 100% continuous direct current (DC) with zero strobing. ZeroDimmer keeps your physical backlight at 100% and uses operating system software color composition to darken pixels before display, giving you comfortable low-light levels with 0 Hz backlight flicker.
Does ZeroDimmer dim the Windows Taskbar and context menus? ▼
Yes! Unlike simple overlay utilities, ZeroDimmer interfaces with the Windows Desktop Window Manager (DWM) Magnification API (MagSetFullscreenColorEffect) at the post-composition stage. This ensures the Taskbar, Start Menu, right-click menus, flyouts, and popups are all uniformly dimmed with zero bright leaks.
Does ZeroDimmer protect OLED and mini-LED displays? ▼
Yes. By lowering the software RGB output values, OLED and mini-LED diodes emit less light per pixel and draw less power, which preserves pixel lifespan, prevents burn-in, and maintains true deep blacks while eliminating the harsh PWM strobing common in OLED panels.
How do I restore brightness if the screen gets too dark? ▼
ZeroDimmer has built-in hardware safety caps (maximum 90% darkness). You can also press the global emergency safety hotkey at any time: Ctrl + Alt + Esc on Windows or Option + Command + Esc on macOS to instantly restore normal 0% darkness.
Is ZeroDimmer completely offline, safe, and private? ▼
100% yes. ZeroDimmer is fully open source under the MIT License, makes zero network connections, has no telemetry, and does not collect any data. It never alters hardware firmware or monitor registers.
